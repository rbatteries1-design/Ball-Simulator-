# Ball-Simulator

A game that was made in HACKCLUB! this game was mostly made with unity and a bit of typescript.

# INFO

You play as a ball. your end goal is to complete 5 levels and make it to the end,

# FEATURES

Wall running, bounce pads, music,

# CONTROLS

WASD - Move up down left right,
ARROW KEYS - move up down left right,
Space - Detatch off walls.
Right Click + mouse - Move the camera (360)
